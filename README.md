LaunchScope is a token launch radar: it reads a sealed snapshot of every protocol DefiLlama tracks, ranks the ones with no token yet by what their launch would be worth (TVL × category multiple × 7-day growth × age with no token), and shows a reader how to farm each one — as a web dashboard that renders with no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
