How the implied value is worked out

implied value = TVL × category multiple × growth factor × age factor × breadth factor

Category multiple

A table by DefiLlama category: what a dollar of TVL in that kind of protocol is worth if it ever issues a token. RWA scores highest, bridges lowest.

Growth factor

1 + the seven-day TVL change, clamped to −50%…+300%, divided by 250. A protocol up 100% in a week scores 1.40; one down 50% scores 0.80. The cap sits at +300% because the snapshot's own figures run that far.

Age factor

1 + 0.30 × log-scaled months since listing, capped at 36 months. A protocol that has run with no token for three years scores 1.30; a newborn scores 1.00.

Breadth factor

1 + 0.015 per extra chain, up to 1.08 for six chains or more. A protocol live on more chains reaches more farmers; a single-chain protocol scores 1.00.

Every row's four factors are shown in its detail view, so any value can be checked against the protocol's own figures. The model is launchscope-2; no protocol name is ever special-cased. Implied values are this entry's own claim, never a prediction that a token will be issued or what it will trade at.

Farm steps are generic guidance derived from a protocol's category and chains. They are not financial advice. Never pay to claim, never share a seed phrase, and check every step on the protocol's own page.

Already launched — the market's own values

These protocols record a token, so they are not on the board. Their market cap is the market's own value, not this model's. They are here so the board's pre-token rows are never confused with tokens that already trade.
